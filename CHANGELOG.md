# Changelog

Notable changes to `@hafbit/acp-components-core` and `@hafbit/acp-components-react` are documented here.

This project follows semantic versioning. Until the first stable release, minor versions may include breaking public API changes; those changes will be called out in release notes.

- Tag-driven npm publishing for synchronized alpha, beta, and stable releases.
- Contribution, security, and issue reporting guidance.
